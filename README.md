# my-Portfolio

영상 중심 개인 포트폴리오 (Next.js App Router + TypeScript + Tailwind CSS).

- 실행: `npm run dev` / 빌드: `npm run build`
- 콘텐츠 교체: `src/data/portfolio.ts` (프로필·연락처·프로젝트). 대괄호 [ ] 값은 플레이스홀더입니다.
- 에셋: `public/` (포스터 `public/placeholder/`, 영상은 `public/videos/` 등에 추가)
- 영상: `video.type` 을 `file` / `youtube` / `vimeo` 로 지정, 임베드는 https 의 YouTube/Vimeo URL만 허용
